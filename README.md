# اینستا تحلیل‌گر | Insta Analyzer

نسخه سورس اندروید: **1.1.0**  
شناسه برنامه: `com.example.instaanalyzer`

## امکانات فعلی
- واردکردن خروجی رسمی Instagram از ZIP یا JSON
- استخراج فهرست followers و following و محاسبه ارتباطات دوطرفه و یک‌طرفه
- بازکردن پروفایل با اقدام مستقیم کاربر
- ثبت دستی آمار دوره‌ای پیج: تعداد فالوورها، فالووینگ، Reach، بازدید پروفایل و تعاملات
- نگهداری تاریخچه آمار روی دستگاه و نمایش تغییر فالوورها بین دو ثبت اخیر
- پیشنهادهای اولیه بر پایه داده‌های واردشده
- پردازش محلی؛ بدون دریافت رمز عبور، کوکی یا نشست Instagram

## راهنمای پایش رشد
1. از بخش «رشد پیج» گزینه «ثبت آمار جدید» را بزن.
2. تعداد فالوورها را وارد کن؛ سایر شاخص‌ها اختیاری‌اند.
3. در ثبت‌های بعدی، تا حد امکان بازه زمانی یکسانی از Instagram Insights یا Meta Business Suite انتخاب کن.
4. ثبت‌ها را منظم و با واحد یکسان انجام بده تا مقایسه معتبر باشد.

## حریم خصوصی و اتصال آینده
این نسخه به Meta API متصل نیست و هیچ داده‌ای را خودکار از Instagram دریافت نمی‌کند. آمار واردشده در حافظه خصوصی برنامه روی دستگاه ذخیره می‌شود. اتصال رسمی فقط در آینده و در صورت فراهم بودن دسترسی مجاز، با OAuth امن و بدون قراردادن Secret یا Token در APK پیاده‌سازی خواهد شد.

## ساخت APK
از تب Actions، گردش‌کار **Build Insta Analyzer APK** را اجرا کن. پس از موفقیت، artifact با نام `Insta-Analyzer-1.1.0-debug` را دریافت کن.

## موارد توسعه بعدی
- دفتر ثبت عملکرد تک‌تک پست‌ها و ریلزها
- تقویم محتوایی و پیشنهاد زمان انتشار
- نمودارهای روند و مقایسه بازه‌ای
- تحلیل رقبا بر پایه داده‌های عمومی و مجاز
- اتصال رسمی Insights در صورت فراهم بودن دسترسی
