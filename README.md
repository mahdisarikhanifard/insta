# دستیار رشد اینستاگرام — Android

یک اپلیکیشن اندروید فارسی برای ساخت ایده و پیش‌نویس محتوای اینستاگرام. کاربر موضوع صفحه و مخاطب هدف را وارد می‌کند، پیشنهاد را می‌بیند و پیش از بازکردن اینستاگرام یا اشتراک‌گذاری کپشن، آن را صریحاً تأیید می‌کند.

## امکانات نسخهٔ فعلی
- تولید پیشنهاد محتوای ساده و کپشن قابل ویرایش بر اساس موضوع صفحه
- نمایش پیشنهاد پیش از هر اقدام
- درخواست تأیید پیش از بازکردن اینستاگرام یا فراخوانی منوی اشتراک‌گذاری اندروید
- واگذاری انتشار نهایی به خود کاربر در برنامهٔ انتخابی
- بدون ورود به حساب، دریافت رمز عبور، جمع‌آوری داده، یا فالو/آنفالو/پیام/انتشار خودکار

پیشنهادها بر اساس ورودی کاربر و قواعد سادهٔ محلی ساخته می‌شوند؛ به آمار واقعی حساب دسترسی ندارند و رشد را تضمین نمی‌کنند. این برنامه راهی برای دورزدن محدودیت‌های اینستاگرام نیست.

## ساخت
- Android Studio با پشتیبانی از Gradle و JDK 17
- Android SDK 35

پروژه را در Android Studio باز کن و ماژول `app` را اجرا یا Build کن. حداقل نسخهٔ اندروید: API 26.

## ساختار
- `app/src/main/java/com/example/instaghbuilder/MainActivity.kt` رابط کاربری و پیشنهاددهندهٔ محلی
- `app/src/main/AndroidManifest.xml` تنظیمات اپ
