# اینستا تحلیل‌گر | Insta Analyzer

نسخه سورس اندروید: **1.0.1**  
شناسه برنامه: `com.example.instaanalyzer`

## امکانات نسخه پایه

- واردکردن خروجی رسمی Instagram از فایل ZIP یا JSON با انتخاب‌گر فایل اندروید
- استخراج فهرست دنبال‌کنندگان و دنبال‌شوندگان از فایل‌های `followers_*.json` و `following.json`
- محاسبه ارتباط دوطرفه، دنبال‌کنندگانِ بدون فالو‌بک متقابل و حساب‌هایی که شما دنبال می‌کنید اما آن‌ها شما را دنبال نمی‌کنند
- بازکردن صفحه عمومی هر نام کاربری با اقدام مستقیم کاربر
- پردازش محلی فایل انتخاب‌شده؛ برنامه رمز عبور یا نشست ورود Instagram را درخواست یا ذخیره نمی‌کند

## ساخت APK با GitHub Actions

1. پروژه با همین ساختار در ریشه مخزن قرار دارد.
2. به تب **Actions** بروید و workflow با نام **Build Insta Analyzer APK** را اجرا کنید؛ تغییرات سورس نیز اجرای خودکار را فعال می‌کنند.
3. پس از پایان موفق اجرا، فایل `Insta-Analyzer-1.0.1-debug` را از بخش Artifacts همان اجرا دریافت کنید.

## محدودیت‌های فعلی

این نسخه هسته تحلیل ارتباطات را فراهم می‌کند. تاریخچه تغییرات فالوورها، تحلیل تعامل/Insights و گزارش‌های پیشرفته تجاری هنوز پیاده‌سازی نشده‌اند. برنامه هیچ عملیات خودکار آنفالو انجام نمی‌دهد؛ هر اقدام باید در Instagram و با تصمیم خود کاربر انجام شود.
