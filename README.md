# اینستا تحلیل‌گر | Insta Analyzer

نسخه اولیه سورس اندروید: **1.0.0**

## ساخت APK با GitHub Actions

1. محتوای این پوشه را مستقیماً در ریشه یک مخزن GitHub بارگذاری کنید؛ پوشه `insta_analyzer` را به‌عنوان یک پوشه تو‌در‌تو در ریشه مخزن قرار ندهید.
2. به تب **Actions** بروید.
3. Workflow با نام **Build Insta Analyzer APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. پس از پایان موفق اجرا، فایل `Insta-Analyzer-1.0.0-debug` را از بخش Artifacts همان اجرا دریافت کنید.

این سورس پایه اولیه است. تحلیل کامل ZIP خروجی Instagram و امکانات پیشرفته هنوز باید توسعه و آزمایش شوند. برنامه رمز عبور Instagram را درخواست یا ذخیره نمی‌کند.
