# اینستا تحلیل‌گر | Insta Analyzer

نسخه سورس اندروید: **2.0.0**  
شناسه برنامه: `com.example.instaanalyzer`

## امکانات نسخه 2.0.0
- واردکردن خروجی رسمی Instagram از ZIP یا JSON و استخراج followers/following
- تحلیل ارتباطات دوطرفه، فالووینگ‌های بدون فالو‌بک و فالوورهای یک‌طرفه
- ثبت تاریخچه آمار رشد حساب و ثبت دستی شاخص‌های Insights
- استودیوی محتوا برای ثبت عملکرد پست، ریلز و استوری
- محاسبه نرخ تعامل مبتنی بر Reach: (likes + comments + shares + saves) / reach
- محاسبه تبدیل Reach به فالوور با استفاده از داده‌های ثبت‌شده
- تقویم محتوایی با وضعیت برنامه‌ریزی‌شده/منتشرشده
- پیشنهادهای قابل توضیح بر اساس داده واقعی ثبت‌شده؛ بدون حدس‌زدن ساعت انتشار
- خروجی CSV عملکرد محتوا از طریق ذخیره‌سازی Android
- ذخیره محلی اطلاعات و عدم دریافت رمز عبور، کوکی یا نشست Instagram

## محدودیت‌ها و حریم خصوصی
این برنامه ابزار تحلیل و رشد حسابی است که مالک آن داده‌ها را وارد می‌کند. تحلیل افراد به‌صورت شخصیت‌شناسی پنهان یا استنباط ویژگی‌های حساس انجام نمی‌شود؛ مخاطب‌شناسی به شاخص‌های تجمیعی محتوا و تعامل محدود است. هیچ ربات فالو/آنفالو، ارسال انبوه پیام یا دورزدن محدودیت‌های Instagram وجود ندارد.

این نسخه به Meta API متصل نیست. دریافت خودکار Insights فقط پس از پیاده‌سازی OAuth رسمی، اخذ مجوزهای لازم و تأیید دسترسی Meta ممکن خواهد بود. هیچ رمز یا توکنی در APK یا مخزن قرار نمی‌گیرد.

## استفاده
1. خروجی رسمی حساب Instagram را از تنظیمات خود Instagram درخواست و فایل ZIP را وارد کن.
2. در بخش رشد پیج، آمار دوره‌ای را با بازه‌های زمانی یکسان ثبت کن.
3. در استودیوی محتوا، Reach و تعاملات هر محتوا را از Insights ثبت کن.
4. در تقویم انتشار، موضوع و تاریخ هدف را برنامه‌ریزی کن.
5. پس از ثبت چند محتوا، پیشنهادهای مقایسه‌ای بر اساس داده‌های واقعی نمایش داده می‌شود.

## ساخت APK
از GitHub Actions گردش‌کار **Build Insta Analyzer APK** را اجرا کن. پس از موفقیت، artifact نسخه 2.0.0 را دریافت کن.
